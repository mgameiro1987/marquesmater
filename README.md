# MarquesMater V5 — Front Office

Base limpa do repositório para o novo método de trabalho.

- Front Office local
- Homepage, categorias, produtos e carrinho
- Opções específicas por tipo de produto
- Menu global
- Sem Back Office nesta fase
- Sem base de dados/pagamentos nesta fase

## Atualização no PC
Depois de clonar este repositório uma vez, usar `ATUALIZAR-SITE.bat` para fazer `git pull` das novas versões.

## Telemóvel
O servidor local pode continuar a servir esta mesma pasta. Depois de atualizar, basta fazer Refresh no telemóvel.
