MARQUESMATER V25 — TESTE LOCAL NO PC

1. Extraia o ZIP para uma pasta no PC.
2. Abra a pasta principal.
3. Execute INICIAR_SITE.bat.
4. O navegador abre automaticamente o site em:
   http://127.0.0.1:8000/

BACKOFFICE:
   http://127.0.0.1:8000/admin.html

NOTAS:
- O projeto usa apenas a biblioteca standard do Python.
- É necessário ter Python 3 instalado no PC.
- O servidor local corre na porta 8000.
- Para parar o servidor, feche a janela "MarquesMater V25 - Servidor".
