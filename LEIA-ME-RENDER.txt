Este pacote mantém a V37 como base e acrescenta apenas a configuração necessária para correr no Render.

Ficheiros acrescentados:
- render.yaml
- este LEIA-ME-RENDER.txt

A porta do servidor foi adaptada para usar a variável PORT fornecida pelo Render.

IMPORTANTE:
- Este pacote é para TESTE.
- O plano Free do Render pode adormecer após 15 minutos sem tráfego e o sistema de ficheiros é efémero.
- NÃO usar o login admin/admin123 num ambiente público definitivo sem alterar as credenciais.

Publicação:
1. Criar um repositório privado no GitHub.
2. Carregar todo o conteúdo desta pasta para a raiz do repositório.
3. No Render: New > Web Service > selecionar o repositório.
4. Escolher Free.
5. Build Command: deixar vazio.
6. Start Command: python server.py
7. Após deploy, abrir o endereço *.onrender.com e acrescentar /admin.html.
