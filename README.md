# MarquesMater V9 — Loja + Backoffice

Base atual do projeto MarquesMater. A V9 parte diretamente do `main` atual e acrescenta o novo backoffice visual, centralizando o catálogo e preparando a gestão da loja.

## V9
- Backoffice intuitivo em `admin.html`
- Dashboard de loja
- Gestão visual do catálogo
- Produtos, categorias, marcas e atributos
- Pesquisa por produto, SKU e marca
- Importar/Exportar preparado para catálogo em massa
- Áreas de encomendas, clientes, relatórios, marketing e configurações
- Layout responsivo para PC e telemóvel
- Front Office V8.5 preservado

## Regras do projeto
Todas as alterações futuras devem considerar as 3 vistas:
1. PC/desktop normal
2. Telemóvel normal
3. Telemóvel com Chrome em “Site para computador”

## Atualização no PC
Depois de clonar este repositório uma vez, usar `ATUALIZAR-SITE.bat` para fazer `git pull` das novas versões.

## Telemóvel
O servidor local pode continuar a servir esta mesma pasta. Depois de atualizar, basta fazer Refresh no telemóvel.
